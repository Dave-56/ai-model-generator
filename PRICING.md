# Pricing Tiers — Tiny Lemon

## Pricing Logic

The framework established a clear image-set hierarchy:

- **Structural minimum:** Front + 3/4 + Back (3 images) — the core PDP angles
- **Full PDP set:** + Detail close-up + Flat lay (5 images)
- **Complete set:** + Lifestyle (7–8 images)

Tiers map directly to this hierarchy. The free tier lets brands experience the output quality. The unlock progression follows the purchase-doubt reduction chain: angles first (removes fit/silhouette doubt), then detail (removes quality doubt), then lifestyle (removes context doubt).

## Tiers

### FREE
*Try before you commit. No credit card.*

**What's included:**
- 3 outfit generations per month (non-rollover)
- 1 model save
- Front hero angle only (no 3/4, no back)
- White studio background only
- Standard resolution (512px output)
- Watermarked downloads
- Community support only

**What's locked:**
- Three-angle structural set (3/4 + back)
- Detail close-ups
- Flat lay
- Lifestyle images
- Multiple models
- High-res output

**Purpose:** Prove the output quality. One generation = one SKU front shot. Enough to see it works, not enough to run a catalog on.

## Pricing Rationale Notes

**Why gate 3/4 + back behind Starter?**
The three-angle structural set is the core product. Free proves quality — Starter is where value begins. A single front shot doesn't eliminate purchase doubt; all three angles do. This is a natural upgrade trigger.

**Why gate detail + flat lay behind Growth?**
Research finding: detail imagery removes the quality doubt that causes abandonment right before checkout. This is a conversion tool, not just a visual nicety. It justifies a meaningful price step.

**Why gate lifestyle behind Scale?**
Lifestyle is the brand-building layer, not the trust layer. It's what the framework defined as the "retention and lock-in" output — it makes shoppers follow you, not just buy. It's also the most generation-expensive image type. Brands at this tier are beyond survival mode; lifestyle is how they build an identity.

**The savings framing (for marketing):**
- Traditional photoshoot day: $500–$2,000 (studio + photographer + model + retouching)
- Traditional cost for 50 SKUs/season at 8 images each: $12,000–$18,000/year
- Scale tier annual cost: $2,988/year — roughly **$10,000–$15,000 saved per year**
